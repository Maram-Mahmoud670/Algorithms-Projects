# 🎂 Birthday Cake Candles

A Python algorithm that analyzes the candles on a birthday cake by finding the tallest candle, counting how many candles have the maximum height, checking whether the tallest candles are positioned symmetrically around the center of the array, and rearranging them when necessary.

---

## 📌 Project Overview

In this problem, a birthday cake contains a number of candles, and each candle has a specific height.

The program performs four main tasks:

1. Find the maximum candle height.
2. Count how many candles have the maximum height.
3. Check whether the tallest candles are placed symmetrically around the center of the array.
4. If the tallest candles are not symmetric, rearrange the candles to make their positions symmetric.

---

# 🎯 Problem Statement

Given an array of candle heights, determine:

- The height of the tallest candle.
- The number of candles that have this maximum height.
- Whether the tallest candles are positioned symmetrically around the center of the array.
- If they are not symmetric, rearrange the candles so that the tallest candles become symmetric.
